# 名字バトル — 決まりと数値

企画の全体は Obsidian の「名字バトル 企画案」にある。ここは**いま実装されている決まりと数値**の一覧。数値を変えたらここも直す。

## 流れ

1. 土地(いまは8都道府県)を選ぶ
2. その土地での割合に応じて5枚引く(同じ名字は重ならない)。何度でも引き直せる(プロトタイプなので無料)
3. コストの合計が **10** までになるよう3枚選ぶ
4. CPU と対戦(相手の土地はランダム。CPU はコストの上限内でいちばん強い3枚を選ぶ)

## 札の性能(`Menko.stats`)

| 性能 | 式 | 範囲の目安 |
|---|---|---|
| 威力 | `32 + 10 × log10(200万 ÷ 全国の人数)`(火は +3) | 佐藤 32 〜 我那覇 59 |
| 重さ | `20 + 0.3 × 画数`(四捨五入。土は +2) | 一戸 22 〜 我那覇 30 |
| 半径 | 字数で 1字 24 / 2字 30 / 3字 36 / 4字以上 40 | |
| 属性 | 名字の字を前から見て、最初に五行を持つ字の属性。なければ「無」 | |
| コスト | 威力 ≤36:1、≤42:2、≤48:3、≤54:4、それより上:5 | |

- 漢字ごとの画数と属性は `src/names.js` の `K`。方角の字は五行の方角に合わせた(東=木、西=金、南=火、中=土)
- **応援**: コストの上限まで余った分 n につき、3枚とも威力 +1・重さ +0.5。よくある名字だけのチームでも戦えるようにするため

## 投げる

- 自分の札を指で引くと、引いた向きの反対へ、引いた長さ × 3 の距離に狙いが付く。上限は 440
- 指を置いた瞬間から勢いのゲージが 0→1→0 と満ち引きする(1往復 1.3 秒)。離したときの値が勢い。0.92 以上は「会心」(表示だけ)
- **試合の1投目は勢いが 0.5 まで**(先に投げるほうの有利を消すため)
- 着地は狙いから最大 `5 + 距離 × 0.05` ぶれる
- 着地点が場の外なら、投げた札が場外になって失う

## めくれるか(`Menko.force`)

- 投げた札 T が L に落ちたとき、ほかの札 X ごとに:
  - `g = |L と X の中心の距離 − X の半径|`(X の縁からのずれ)
  - 届く幅 `0.75 × T の半径 + 0.55 × X の半径`。g がこれ以上なら影響なし
  - 力 = `T の威力 × (0.35 + 0.65 × 勢い) × (1 − g ÷ 届く幅) × 相性`
  - 力 × (0.85〜1.15 の乱数) が X の重さを超えたらめくれる(味方の札も巻きこむ)
  - めくれなければ、L から離れる向きに最大 26 動く。場の外に出たら失う
- 相性(相克): 木→土→水→火→金→木。矢印の先に 1.1 倍、逆向きは 0.92 倍
- 投げたあと、重なった札は離す

## 勝ち負け

- 相手の札がすべてなくなったら勝ち(めくれる・場外)
- 10回(両者が10回ずつ投げる)で終わらなければ、残った枚数が多いほうの勝ち。同じなら引き分け

## CPU(`Menko.cpuPlan`)

- 自分の札 × 相手の札 × 縁の16方向を試し、「相手をめくる見込み − 味方を巻きこむ見込み − 場外に出る心配」がいちばん高い所を狙う
- 腕前 0.75: 狙いが標準偏差およそ 10 ぶれ、勢いは 0.83〜1.0

## 2026-10-20 の sim の結果(3000試合、CPU どうし)

- 平均 4.0回で決着。1投で相手を平均 0.58枚めくる
- 先に投げたほうの勝率 48%
- 土地ごとの勝率 40〜57%(北海道・新潟・東京が高く、大阪・福岡・鹿児島が低い)
- コストごとの勝率はほぼ同じ(コスト5だけ 44%)

### わかったこと

- **重さ(画数)の差が勝ち負けをいちばん左右する**。「藤」「橋」の多い北・東の名字は重く、「田」「中」「山」の多い西・南の名字は軽い。重さの式を `8 + 画数` から `20 + 0.3 × 画数` に縮めて差を減らした
- 属性も土地ごとに偏る(東日本は木、西日本は土が多い)。木は土に強いので、相性を強くすると西日本が不利になる。いまは 1.1 / 0.92 と弱め
- 沖縄の名字は全国では珍しく、コストが重い。上限 9 では半分ほどしかチームを組めなかったので 10 にした
- 仮のデータの話なので、本物のデータに差し替えたらもう一度 sim で見直す
